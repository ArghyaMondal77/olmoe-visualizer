THE UNEMBEDDING MATRIX

In many architectures, the W_unembed matrix is exactly the same matrix as the Input Embedding (W_E) from the Tokenizer, just transposed. This saves millions of parameters (Weight Tying).

It takes the abstract 2048-dimensional "thought" the network formed and mathematically maps it back into the 50,304 concrete words we humans understand.

THE SOFTMAX BOTTLENECK

The matrix multiplication produces Logits—raw confidence scores that can range from -100 to +100.

The Softmax function forces these 50,304 unbounded numbers into a strict probability distribution that sums exactly to 1.0 (100%). This step is what allows the model to calculate its "certainty" about the next word.

GREEDY VS. SAMPLING

Our visualization uses Argmax (Greedy Decoding), which always blindly picks the single highest probability (98.2%).

In reality, we often use Temperature and Top-P sampling. Instead of always picking the #1 word, the model rolls a weighted multi-sided die based on these probabilities, allowing it to generate creative, varied text rather than robotic repetition.
