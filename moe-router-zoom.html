Step 0: The 2048-dimensional token arrives at the MoE block. It must be evaluated to determine which 8 experts will process it.

THE GATING MATMUL

Before any heavy math is done, the token (x) is multiplied by the W_gate matrix. Because the matrix has 64 columns, the output is exactly 64 numbers (logits).

These logits represent how "qualified" each of the 64 experts is to process this specific word.

TOP-8 SELECTION MASK

OLMoE uses a Top-8 routing strategy. It sorts the 64 logits and identifies the 8 highest values.

What happens to the other 56? They are mathematically masked with -∞. This ensures they are completely annihilated in the next step and require zero compute power.

SOFTMAX PROBABILITIES

A Softmax function is applied to the array. Because e^-∞ = 0, all 56 dropped experts receive exactly 0.000 probability.

The 8 surviving experts receive probability weights that sum perfectly to 1.0 (100%). These weights are used to merge their outputs later.
